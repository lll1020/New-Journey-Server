# Codex 项目级配置

该目录用于存放项目级的 Codex 上下文信息。

## 文件说明

- `project_prompt.md`：项目长期提示词（给 Codex 的执行约束）。
- `project_config.json`：机器可读的项目默认配置与关键路径。

## 使用约定

1. 核心业务规则统一维护在这里。
2. 业务规则变更时，优先更新本目录。
3. 提示词与配置必须与当前代码保持一致。
## 官方文档

- 996M2 引擎官方文档：https://engine-doc.996m2.com/web/#/9/154

## 代码注解约定

- 新增方法时必须添加注解。
- 超过 20 行的长代码块必须增加块级注解。
